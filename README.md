# 项目名称
通讯录管理系统<addressbooks>
一个基于 C++ 控制台的通讯录管理程序，支持联系人的增删改查等基本操作


## 功能
- 1. 添加联系人（姓名、性别、年龄、电话、地址）
- 2. 显示所有联系人
- 3. 删除指定联系人
- 4. 查找联系人（按姓名查找）
- 5. 修改联系人
- 6. 清空全部通讯录
- 0. 退出系统

## 技术要点
- 语言：C++
- 开发环境：Visual Studio / 小熊猫Dev-C++
- 主要知识点：
  - 结构体（struct）的嵌套使用
  - 数组存储数据
  - 函数封装与模块化
  - 指针操作
  - 控制台清屏与暂停

## 使用方法
1.用 Visual Studio /小熊猫Dev-C++ 打开  
2.编译运行
![alt text](<屏幕截图 2026-11-08 203009-1.png>)
3.按菜单提示输入数字操作
4.按提示输入联系人信息即可

## 文件说明
  main.cpp    - 主函数和菜单
  manage.h    - 结构体定义和函数声明
  manage.cpp  - 所有功能函数的具体实现
